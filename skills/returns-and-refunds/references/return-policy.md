# Our return policy, in plain words

We want you to be happy with what you bought. Here's how returns work.

## What can be returned

- **Delivered orders.** You can start a return once your order has been delivered. If it's still being prepared or is on its way, wait until it arrives.
- **One return per item.** If you've already returned an item, it can't be returned again.
- **Final-sale items can't be returned.** Items marked final sale are sold as-is.

## How long you have

- **Electronics: 15 days** from the day your order was delivered.
- **Everything else: 30 days** from the day your order was delivered.

The days are counted from the delivery date, not the order date.

## Your refund

- You get back what you paid for the item: the item price times the quantity you're returning.
- After the return is created you'll receive a return id and a prepaid return label link. Pack the item, attach the label, and drop it off with the carrier.

## Something special?

If an item arrived damaged or faulty, or you think your case deserves a closer look, we can open a support ticket so our team can review it. We can't promise an outcome, but a person will look at it.
