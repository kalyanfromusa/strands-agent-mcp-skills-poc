How to get a token

Quickest: the helper signs in a demo user from .deploy/users.json.

.venv\Scripts\python.exe scripts\chat_ui.py --print-token alice

Or with the AWS CLI (use the AccessToken, not the IdToken):

aws cognito-idp initiate-auth --region <region> --auth-flow USER_PASSWORD_AUTH --client-id <cognito_users_client_id> --auth-parameters USERNAME=alice,PASSWORD=<password> --query AuthenticationResult.AccessToken --output text

From the AWS console (no local AWS CLI needed):

  1. Pick the deployment's region (top right), open Amazon Cognito → User pools → shopassist-pool → App clients → shopassist-users (left menu, under Applications) and copy the Client ID.
  2. Open CloudShell (terminal icon in the console's top bar).
  3. Run the command above with that client id and the user's password from .deploy/users.json.
  4. Copy the printed token and paste it here.

The users client only allows USER_PASSWORD_AUTH (no hosted login page), so the console's "View login page" won't issue a token for it. Details: docs/11-chat-ui.md.

Tokens expire after 60 minutes. An M2M (client_credentials) token is rejected by the agent runtime.
